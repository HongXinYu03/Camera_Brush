# Camera Brush · 路线工作台

在已有 Vue 3 + TypeScript + Vite 工程上开发的纯前端工具。现在只保留一个灰白配色的路线工作台，打开即用。

## 启动

Windows PowerShell：

```powershell
cd 'C:\Workspace\Git program\Camera_Brush'
# 已安装依赖时可以跳过
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --strictPort
```

Linux / macOS：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
```

打开 `http://127.0.0.1:5173/`。Node.js 版本要求沿用现有项目配置：`^22.18.0 || >=24.12.0`。无需 Python、后端或模型服务。

## 使用

1. 点击左侧“导入场景图片”，支持批量 PNG、JPEG、WebP。首次使用显示空白工作区，不自动创建演示数据。
2. 在场景上按住鼠标画线；可切换固定宽度或速度映射笔刷。笔刷设置默认收起。
3. 选择、整体移动、编辑顶点、反向或删除笔划；支持撤销与重做。
4. 在右侧填写路线名称和运动意图（选填）。编辑会自动保存，点击“保存”建立路线版本。
5. 可导出原图尺寸叠加 PNG、透明路线 PNG、路线 SVG，或使用顶部“导出备份”保存完整 ZIP。通过“导入备份”恢复为独立副本。

左侧“当前图片新建路线”可在同一张图片上创建不同任务。已有多个工作区时显示切换下拉框。

每条路线右侧的垃圾桶按钮用于**删除其底图及该底图下的全部路线**。确认窗口会显示文件名和关联路线数量，取消不会修改数据。删除后自动切换到其他可用路线；全部删除后回到空白工作区。点击侧栏“恢复最近删除”可按删除顺序逐张恢复，包括原笔划、意图和历史版本，刷新后仍可恢复。

图片删除采用可恢复的移除方式：不立即清理原始文件，不影响历史快照、其他工作区或已下载的备份，因此不用于释放浏览器存储空间。完整 ZIP 备份包含这些可恢复记录；仅模型输入导出排除已移除图片。

快捷键：B 绘制，V 选择/移动，E 编辑顶点，H 平移，Space 临时平移，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Ctrl+S 保存，Delete 删除。编辑顶点时双击路线插点，Alt+单击顶点删点。

单张图片上限：40 MB、3200 万像素，单边最大 16384 px。导入规范化 EXIF 朝向、保留源文件并使用 SHA-256 去重。支持 8192 × 2048 长卷，但本次未完成长卷的浏览器实际验收。

## 保存与备份

数据保存在当前浏览器的 IndexedDB（`camera-brush`）中，不写入项目文件夹。约 700 ms 自动保存，草稿另存；跨标签页版本冲突会提示保留副本或重新加载。

请固定使用同一个地址和端口。`localhost` 与 `127.0.0.1`、不同端口或不同浏览器的数据相互独立。清理浏览器站点数据会删除本地记录，建议定期导出 ZIP。导入 ZIP 默认创建独立副本，不覆盖现有项目。

ZIP 无需外部依赖，包含源图、规范图、当前路线、原始采样、意图与历史记录。读取校验路径、大小、CRC、SHA-256 和数据引用；导出单包最大 254 MB/5000 文件，导入展开最大 256 MB。

## 验证与结构

```sh
npm test
npm run test:views
npm run build
```

核心测试覆盖坐标、速度线宽、原始采样保留、版本、输入过滤、ZIP 往返及数据兼容约束；页面冒烟检查针对精简工作台。SSR 检查不代替浏览器实际交互，当前尚未完成浏览器截图和交互验收。

- `src/App.vue`：单页入口、图片/任务列表、备份操作。
- `src/components/Workspace.vue`：路线编辑、笔刷和意图。
- `src/components/RouteCanvas.vue`：原生 Canvas、坐标变换与 Pointer Events。
- `src/composables/useApp.ts`：自动保存、草稿、图片导入与工作区切换。
- `src/lib/geometry.ts`：速度映射与变宽几何。
- `src/lib/storage.ts`、`data.ts`、`zip.ts`：本地存储及兼容数据包。
- `src/style.css`：灰白主题与响应式布局。

生产构建输出 `dist/`，可执行 `npm run preview` 预览；不要直接双击 HTML。没有部署或发布。
